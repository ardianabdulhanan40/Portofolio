Tentang Saya

Perkenalan

Nama saya Ardian Abdul Hanan, bisa memanggil saya Ardian. Saat ini, saya sedang menempuh pendidikan pada program studi Rekayasa Perangkat Lunak di Politeknik Negeri Subang. Rasa penasaran dan ketertarikan saya terhadap dunia teknologi membawa saya untuk mendalami bidang ini. Saya adalah pribadi yang suka belajar hal baru, terbiasa bekerja secara mandiri maupun tim, dan senang menghadapi tantangan dalam menyelesaikan masalah.

Hobi

Saya menyukai aktivitas olahraga seperti badminton dan tenis meja, serta senang melakukan eksplorasi alam untuk menyegarkan pikiran dan mencari inspirasi.

Keahlian
